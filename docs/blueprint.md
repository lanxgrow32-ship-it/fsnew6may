# **App Name**: PropStar Admin

## Core Features:

- User Authentication: Secure user login with email and password enforced by Supabase Auth.
- Role-Based Access Control: Admin and user roles to control access to different parts of the application, managed in Supabase.
- Admin Dashboard: Centralized dashboard for administrators to manage users, create accounts, and view activity logs.
- User Creation: Admins can create new user accounts with auto-generated passwords.
- Profile Management: Admins can set trading usernames and passwords and also update general user details.
- Activity Logging: Log all admin actions such as user creation, credential updates, providing an audit trail.

## Style Guidelines:

- Primary color: Dark slate blue (#475569) for a professional and trustworthy feel.
- Background color: Very dark gray (#0F172A) to enhance the dark theme.
- Accent color: Muted lavender (#A78BFA) for highlights and call-to-actions.
- Body and headline font: 'Inter', sans-serif, for a modern and clean interface.
- Use simple, outlined icons from Lucide to maintain a minimal style.
- Emphasize card-based layouts with ample spacing to create a clean, organized interface.
- Subtle loading animations using the Loader2 component for user feedback.
